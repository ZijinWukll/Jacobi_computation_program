> **一句话概括**：纯 C++ 实现、多线程并行、支持 10 万比特大整数的 Jacobi 符号极速计算器。
> 100 对随机 10 万比特测试仅需 **~0.4 秒**，比纯 Python 实现快 **数千倍**。

### 核心技术优势

1. **硬件级 128 位算术**：利用 `unsigned __int128` 类型，一条 `MULQ` 指令完成 64×64→128 位乘法和 128÷64→128 位除法
2. **Lehmer 加速取模**：从大整数的最高 1–2 个 64 位字估计商，避免逐位长除法
3. **q=2 快速路径**：最常见的商 `q=2` 用左移替代 128 位乘法，节省约 15% 模运算时间
4. **多线程并行**：`std::async` 自动利用全部 CPU 核数，16 核加速比 > 10 倍
5. **静态链接**：生成的 `.exe` 无任何外部 DLL 依赖，开箱即用
6. **全编译器优化**：`-O3 -march=native -flto` 发挥本机 CPU 全部指令集能力

## 第一讲：数论背景——从 Legendre 符号到 Jacobi 符号

### 1.1 为什么需要这个符号？

在数论中，我们经常要判断一个整数 `a` 是否模另一个整数 `n` 的**二次剩余**，即方程

```
x² ≡ a (mod n)
```

是否有整数解。这个问题在密码学（如 RSA、Goldwasser-Micali 加密）、素性测试（Solovay-Strassen 算法）和代数数论中处在核心位置。

### 1.2 Legendre 符号

设 `p` 为**奇素数**。Legendre 符号 `(a/p)` 定义为：

```
        ⎧  0,  若 p | a
(a/p) = ⎨  1,  若 a 是模 p 的二次剩余
        ⎩ -1,  若 a 是模 p 的二次非剩余
```

即判断 `a` 在模 `p` 下能否开平方。

#### Euler 判别法

```
(a/p) ≡ a^{(p-1)/2} (mod p)
```

这给出了直接计算 Legendre 符号的方法，但当 `p` 很大时，指数运算非常慢。

#### 二次互反律（Gauss 1801）

对两个不同的奇素数 `p`、`q`：

```
(p/q)(q/p) = (-1)^{(p-1)(q-1)/4}
```

等价写作：

```
          ⎧ -(q/p),  若 p ≡ q ≡ 3 (mod 4)
(p/q) =  ⎨
          ⎩  (q/p),  其他情况
```

这个漂亮的定理将 `(p/q)` 的计算归结为 `(q/p)`，后者通常更小，从而可以递归下去。

### 1.3 Jacobi 符号

Jacobi 符号是 Legendre 符号的**推广**。设 `n` 为**正奇数**，素因数分解为 `n = p₁p₂⋯pₖ`，则：

```
(a/n) = (a/p₁)(a/p₂)⋯(a/pₖ)
```

其中右侧是 Legendre 符号。

**关键性质：**
- 若 `(a/n) = -1`，则 `a` 一定是模 `n` 的二次非剩余
- 若 `(a/n) = 1`，`a` 不一定是模 `n` 的二次剩余（因为偶数个 `-1` 相乘也得 `1`）
- Jacobi 符号满足**完全相同的二次互反律**，这使其可高效计算

### 1.4 算法：二进制 Jacobi 符号

我们不分解 `n`，而是直接计算 `(a/n)`。算法基于以下规则：

**规则 1：** 若 `a = 0`，则 `(0/n) = 0`（若 `n=1` 则为 `1`）

**规则 2：** 从 `a` 中提取因子 2：

```
(2a'/n) = (2/n)(a'/n)
```

其中 `(2/n) = 1` 若 `n ≡ ±1 (mod 8)`，`(2/n) = -1` 若 `n ≡ ±3 (mod 8)`

**规则 3：** 若 `a` 为奇数，应用二次互反律：

```
(a/n) = (-1)^{(a-1)(n-1)/4}(n mod a / a)
```

即将 `(a/n)` 转化为 `(n mod a / a)`，交换角色并取模，使数字变小。

**规则 4：** 当 `a = 1` 时，`(1/n) = 1`。

**伪代码：**

```
function jacobi(a, n):
    result = 1
    while a ≠ 0:
        // 提取 a 中的因子 2
        t = trailing_zeros(a)    // a 中因子 2 的个数
        a >>= t                  // 去掉所有因子 2
        if t 是奇数:
            if n mod 8 ∈ {3, 5}:
                result = -result
        
        if a == 1: return result
        
        // 二次互反律
        if a ≡ n ≡ 3 (mod 4):
            result = -result
        
        swap(a, n)
        a = a mod n
    
    // a 为 0，说明 n 与 a 有公因子
    if n == 1: return result
    else: return 0
```

### 1.5 计算瓶颈：大整数取模

每次循环都要做 `a = a mod n`。对于 10 万比特的大整数，朴素除法慢如龟爬。我们使用 **Lehmer 加速除法**：

- 每次只比较 `a` 和 `n` 的最高几个 64-bit "数字"（limb）
- 估计商 `q ≈ a_hi / n_hi`
- 执行 `a -= q × n`（一次 O(k) 的乘减操作）

因为 `a` 和 `n` 通常很接近（只有 0–1 个 limb 的高度差），`q` 往往是 2 或 3，乘减操作非常高效。

### 1.6 复杂度

对 `k` 比特的大整数，算法时间复杂度约为 `O(k²)`，实际测量约 `O(k^1.73)`。在 16 核 CPU 上，10 万比特的 100 对测试约 0.4 秒完成。

### 2.2 各文件功能详解

#### `include/bigint.h`

声明 `BigInt` 类，核心是大整数用 **`vector<uint64_t>`** 以小端序存储（`d[0]` 是最低 64 位）。

| 方法 | 说明 |
|------|------|
| `BigInt()` | 构造 0 |
| `BigInt(uint64_t)` | 从 64 位整数构造 |
| `BigInt(const string&)` | 从十进制字符串构造（9 位分组加速） |
| `is_zero()` / `is_one()` | 快速判零/判一 |
| `trailing_zeros()` | 二进制末尾 0 的个数（提取因子 2） |
| `shr(n)` | 右移 n 位 |
| `cmp(o)` | 比较：-1/0/1 |
| `sub(o)` | 减去 `o`（`this >= o`） |
| `mod(o)` | 取模 `this %= o`（Lehmer 加速） |
| `mod4()` / `mod8()` | 快速 `mod 4` / `mod 8` |
| `sub_mul(b, q)` | `this -= q * b` |
| `to_string()` | 转十进制字符串 |

#### `include/jacobi.h`

```cpp
int jacobi(BigInt a, BigInt n);
```
返回 Jacobi 符号 `(a/n)` 的值：`1`、`-1` 或 `0`。

#### `src/bigint.cpp`

关键实现细节：

**十进制构造**：将输入字符串每 9 位一组处理。对每组：`d = d × 10⁹ + chunk`。每次乘法用 `unsigned __int128` 完成 64×64→128 位乘法，单条 `MULQ` 指令。

**Lehmer 取模**：`mod(n)` 函数的三个分支：

- **等高**（`|a| == |n|`）：比较最高 limb，若 `a_hi > n_hi` 则估计商 `q = a_hi / (n_hi + 1)`，执行 `sub_mul(n, q)`。`q = 2` 时使用左移代替乘法（快速路径）。
- **差 1 位**（`|a| == |n| + 1`）：用 `a` 的最高两个 limb 估计商。
- **差 ≥2 位**（罕见）：用 128/64 位除法估计商。

**q=2 快速路径**：`sub_mul(n, 2)` 被替换为 `a -= n << 1`，左移一位即可，无需 128 位乘法。

#### `src/main.cpp`

读取 100 对 `(m, n)`，使用 `std::async` 多线程并行计算 Jacobi 符号，顺序输出结果。线程数由 `thread::hardware_concurrency()` 自动获取。

#### `src/jacobi.cpp`

二进制 Jacobi 算法实现，完全遵循 1.4 节的伪代码。

#### `test/test_runner.py`

Python 性能基准测试。生成 100 对随机的 `k` 位整数，调用 `jacobi_main.exe` 计算，验证结果正确性（用纯 Python 的 Jacobi 实现对照）并计时。在 `k = 100000`、100 对的条件下，期望用时 ≤ 1 秒。

## 第三讲：使用教程

### 3.1 环境要求

- **操作系统**：Windows（需安装 MSYS2）
- **编译器**：MSYS2 mingw64 GCC（C++17 支持）
- **Python**：3.8+（仅用于测试脚本）
- **推荐配置**：8 核以上 CPU（多线程加速明显）

### 3.2 安装 MSYS2 编译器

如果尚未安装：

1. 从 https://www.msys2.org 下载安装
2. 打开 **MSYS2 UCRT64** 终端
3. 依次执行：
```bash
pacman -Syu
pacman -S mingw-w64-ucrt-x86_64-gcc
```

或者在 `build.sh` 中修改 `CXX` 路径指向你的 GCC。

### 3.3 快速开始

**第一步：编译**

在项目根目录（`E:/Desktop/数论作业5/`）打开 Git Bash 或 MSYS2 终端：

```bash
# 编译主程序 + 运行测试
bash build.sh all
```

这将生成 `jacobi_main.exe` 并运行全部单元测试。

**第二步：运行主程序**

```bash
bash build.sh main
./jacobi_main.exe
```

程序从标准输入读取数据。输入格式：

- 第 1 行：整数 `k`（表示测试位数，仅用于内部参考）
- 后续 200 行：100 对 `(m, n)`，每对两行，每行一个十进制大整数

**示例输入：**

```
5
13
21
99
101
```

表示 `k = 5`，两对测试：`(13, 21)` 和 `(99, 101)`。输出：

```
-1
-1
```

每行一个结果，对应每对 `(m, n)` 的 Jacobi 符号值（`1`、`-1` 或 `0`）。

**第三步：运行自动测试**

```bash
python test/test_runner.py
```

这会自动编译主程序，然后从 `k = 1` 开始指数搜索，二分查找使 100 对测试在 1 秒内完成的最大 `k` 值。

**单点测试：**

```bash
python test/test_runner.py --dry-run 50000
```

测试 `k = 50000` 时 100 对的性能和正确性。

**手动设置最大搜索范围：**

```bash
python test/test_runner.py --max-k 200000
```

### 3.5 如何判断正确性和性能

**正确性：**

- `bash build.sh test` 运行 59 项 BigInt 测试 + 29 项 Jacobi 测试
- `test_runner.py` 使用纯 Python Jacobi 实现进行交叉验证

**性能：**

- `test_runner.py` 输出每轮测试的耗时，单位 ms

- 目标：`k = 100000` 时 `< 1000ms`

性能解读示例：


### 3.6 常见问题

**Q：编译报错找不到头文件？**
确保在项目根目录执行 `build.sh`，并且 MSYS2 已正确安装。

**Q：`jacobi_main.exe` 闪退？**
尝试在终端中直接运行 `./jacobi_main.exe` 并手动输入数据，查看错误信息。

**Q：Python 脚本报 `FileNotFoundError`？**
确保先执行过 `bash build.sh main` 生成了 `jacobi_main.exe`，或者在项目根目录运行脚本。

**Q：测试结果与预期不一致？**
检查输入的 `n` 是否为正奇数（Jacobi 符号要求）。如果 `n` 为偶数，程序行为未定义。

**Q：如何在自己的项目中使用？**
核心文件只需 `include/bigint.h`、`include/jacobi.h`、`src/bigint.cpp`、`src/jacobi.cpp`。编译时加 `-Iinclude` 并链接这两个 `.cpp` 文件。
